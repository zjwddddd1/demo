核心命令速查

常用 5 条 
# 创建会议（时间必须 ISO 8601 + 时区）
tmeet meeting create \
  --subject "测试会议" \
  --start "2026-06-08T13:00+08:00" \
  --end "2026-06-08T13:30+08:00" \
  --timezone "Asia/Shanghai"

# 列已结束会议（按周/按客户做盘点用）
tmeet meeting list-ended \
  --start "2026-06-01T00:00+08:00" \
  --end "2026-06-07T23:59+08:00" \
  --page-size 30 --format json

# 按时间窗反查录制（不限主持人，最关键的一条）
tmeet record list \
  --start "2026-06-05T16:00+08:00" \
  --end "2026-06-05T18:30+08:00" \
  --format json-pretty

# 拉智能纪要（结构化 AI 总结）
tmeet record smart-minutes \
  --record-file-id 2062817477450366977 \
  --format json-pretty

# 把 MDX 推到腾讯文档（智能画布）
mcporter call tencent-docs create_smartcanvas_by_mdx \
  --args '{"title":"...", "mdx":"..."}'

踩坑经验

2 次以上才趟通的坑
⚠️ 录制反查必须用时间窗，不能直接用 meeting-code
tmeet record list --meeting-code XXX 只返回当前用户主持的录制。如果会议是别人主持的（如团队同事帮你拉录制），这个查询会返回 0 条 → 误判「没开云录制」。
正确做法：用 --start / --end 时间窗反查，会列出所有可见录制。
⚠️ 时间格式必须 ISO 8601 带时区
tmeet meeting create 不接受 2026-06-08 13:00 这种格式，必须是 2026-06-08T13:00+08:00。
否则会被解析为 UTC，导致会议时间偏移 8 小时。
⚠️ list-ended 的 page-size 上限是 30
超过 30 会被自动 clamp 并往 stderr 写警告。需要更多数据要分页（用 --page 参数），不要傻傻地传 100。
⚠️ 旧 SKILL 文档里的 schedule_meeting 是过期命令
实际命令名是 tmeet meeting create，不是 schedule。如果搜到 tmeet meeting schedule 不要直接照搬，先用 tmeet meeting --help 核对。
⚠️ 智能纪要依赖云录制，没录就没纪要
smart-minutes 需要 record-file-id，而 record 只有开了云录制才会生成。建议：客户场会议默认开云录制，否则 AI 整理纪要这条工作流会断在第一步。
