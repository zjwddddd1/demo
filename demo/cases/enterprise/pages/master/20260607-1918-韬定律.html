Richard Feynman · 费曼
物理直觉 · 第一性回到现象 · 警惕命名魔术

好。我先把某科技公司这套讲法翻译成傻子也懂的版本——这是我的第一道工序。如果一个东西不能用最朴素的语言讲清楚，那它要么我没懂，要么讲的人也没懂。

翻译：芯片性能由两件事决定——晶体管多不多，信号跑得快不快。摩尔定律是把晶体管做小，多塞几个。某科技公司说现在做小做不动了（光刻机被卡），那我们换一招——少在尺寸上较劲，多在"信号从 A 跑到 B 要多久"上较劲。怎么压缩这个时间？把电路立体堆起来（3D 堆叠），缩短走线；优化 RC（电阻 × 电容）；改总线协议；芯片和软件一起设计。

这套东西，作为工程实践，我给它鼓掌——因为它管用。麒麟 2026 实测晶体管密度 +55%、能效 +41%，量产 381 款芯片，这是数据，不是 PPT。

但作为"定律"——我犹豫。τ 是个老朋友。RC 时间常数从基尔霍夫年代就在那儿。"以 τ 缩微为优化目标"这件事，在系统级、跨层级被明确提为统一原则——这是新的。但 τ 本身不是新发现的物理量。

There's a difference between knowing the name of something and knowing something. ——叫得出名字和真的懂，是两回事。"韬定律"是个名字。它背后是真物理，但名字不能替代你做出来的那个东西。我会更看重 381 款芯片，少看一点"定律"这个词。

我担心的是什么？当工程实践被升级为"定律"，有时候会引入一种不可证伪的修辞——只要任何成功，都算"τ 在起作用"；任何失败，都算"τ 还没压到位"。这是危险的。波普尔会比我说得更狠，我先放下话筒给他。

我能给的判断：

  • (L1 物理层) τ 不是新东西。把"系统时延"作为统一指标贯穿全栈，是值得肯定的方法论组织——但这是方法论。
  • (L2 工程层) 逻辑折叠 = 3D 堆叠 + 平面到立体的电路重构。业界做了很多年，某科技公司是把它系统化、量产化，这功劳是真的。
  • (L3 命名层) "定律"用得过重了。但不致命——历史上"黄氏定律"也被这么叫，行业有这个习惯。

Elon Musk · 马斯克
第一性原理 · 工程师视角 · "停止用比喻，告诉我具体数字"

好，让我用我的方式来。先扔掉所有形容词，就看变量。

性能 P 由若干因素决定，最朴素地：P ≈ f(晶体管密度 D, 时钟频率 / 时延 1/τ, 架构效率 η, 功耗预算 W)。摩尔定律押注 D。某科技公司说他们现在押注 1/τ。从第一性原理看，这本来就该一起优化，没什么"哪个替代哪个"——任何严肃工程师都知道你不能只看一个变量。

所以"τ 替代几何"这个表述，从严格物理上是不准确的。几何缩微减小 D 的同时也减小 RC，所以两者不是替代关系，是耦合的。准确的说法应该是："当 D 不能继续推进时，更激进地推进 1/τ 的优化"——这是策略转移，不是范式革命。

但策略转移本身值得尊重，因为它选择了正确的剩余变量去发力。当你被卡死在一个变量上，识别出"还有哪些变量可以推"，并把全部资源压上去——这是优秀工程组织的标志。SpaceX 不能用一次性火箭与波音卷价格，所以我们押全部筹码到可重复使用——同一个逻辑。

If you're not using physics first principles, you're using analogy. Analogies fool you when the analogy fits. ——比喻骗你，恰恰发生在它看起来很贴的时候。"时间折叠 vs 空间折叠"这个比喻很美，但它是 PR 修辞，不是物理。

但我必须给某科技公司公道：381 款芯片量产 + 麒麟 2026 实测 +55% 密度——这不是 PPT，这是 hardware in production。当我看到一家公司在被切断 EUV、被切断顶尖 EDA、被切断台积电先进制程的情况下，仍然在 6 年里量产了几乎所有方向的芯片——这是很硬的。我会把这个评价拆开：

  • "韬定律"作为定律：勉强 2/5——它不是物理定律，是工程战略。
  • "韬定律"作为工程战略：4/5——选择了正确的变量，做了系统级整合。
  • 某科技公司这家公司的执行力：5/5——在最严苛约束下保持了量产节奏。

2031 对标 1.4nm 的承诺——这是关键点。如果做到，韬定律就站住了；做不到，就是一次包装。我倾向相信他们能做到 70-80% 的目标（每瓦性能可能差一截，但晶体管密度等效是有可能的），因为他们已经用 6 年证明了这套方法的可重复性。

吴晓波
商业史 · 周期视角 · 中国民营企业研究

从 1965 年摩尔在《电子学》杂志写下那条经验曲线，到 2026 年何庭波在 ISCAS 提出韬定律——整整 61 年。这 61 年里，全球半导体行业的"语法"都是美国人写的：摩尔定律 (1965)、登纳德缩放 (1974)、黄氏定律 (2018)。这是第一次，一个中国公司试图书写这门语言的下一章。

这件事的意义，不能只在物理意义上评估。要放回中国半导体史的周期里看：

  • 2000-2014 · 跟随期：从 90nm 到 28nm，中国晶圆厂亦步亦趋追赶国际先进。代表事件：中芯国际成立、华虹追赶。
  • 2015-2019 · 突破期：海思崛起、麒麟 970 自研 NPU、5G 模块自给。摩尔定律仍是公认范式。
  • 2019-2025 · 制裁期：5 月 16 日实体清单、EUV 禁运、EDA 断供。"卡脖子"成为关键词。
  • 2026- · 范式期：韬定律的发布，标志着中国半导体从"追随别人定义的赛道"到"尝试定义自己的赛道"。

这是第一个意义。第二个意义更深：这是中国民营企业第一次在受制裁的极限压力下提出全行业级的指导原则。和当年某科技公司的 IPD（从 IBM 学来的产品开发流程）不一样，韬定律是原生于自身困境的方法论。"被卡住" → "另辟蹊径" → "把蹊径系统化" → "把系统化升格为原则"——这是一个非常完整的中国式企业进化路径。

但我要泼冷水。"定律"这个词，承担了它本不该承担的国家叙事。何庭波本意可能就是一个工程方法论的总结，但落到舆论场，"中国版摩尔定律"被赋予了地缘抗争的象征。这种象征会反噬技术本身——它会让市场对它要求过高（你要打败摩尔！），也会让批评者陷入"骂韬定律 = 不爱国"的二元陷阱。

中国企业最危险的时刻，往往是它被国家叙事绑架的时刻。柳传志、张瑞敏、任正非——三代人都在这条路上栽过。技术成果是 6 年累积的硬功夫，但当它被升格为"民族叙事"，技术评估的空间就缩小了。

我的判断：

  • (L4 商业层) 6 年 381 款芯片是真硬数据。麒麟 2026 +55% 密度是真硬数据。这家公司确实做到了不可思议的事。
  • (L5 历史层) 这是中国半导体史上的分水岭事件，无论"定律"是否成立。分水岭的标志不是结果，是命名权易手——从这一天起，全球半导体行业讨论的范式表里，多了一个中国名字。
  • (L3 命名层) 但这把命名权用得稍重。叫"何氏方法论"或"τ 范式"都比"韬定律"稳一些——前者在赢，后者在赌。

Karl Popper · 波普尔
科学哲学 · 可证伪性 · 划界问题

等一下。在你们把这叫"定律"之前——请告诉我，什么样的观察会让你们承认"韬定律是错的"？

这是 demarcation problem——划界问题。一个命题要进入科学，必须能被设想出可使其失败的观察。"韬定律"在严格意义上，没有给出这个测试。我们逐条审视：

  • "以 τ 缩微替代几何缩微"——这是规范性陈述（应该这样做），不是描述性陈述（自然就这样）。规范性陈述无所谓真假，只有用与不用。摩尔定律在 1965 年也是经验观察 + 行业自我实现的预言，但它至少给了量化指标（每 18-24 个月翻倍），韬定律没有等价的量化承诺。
  • "2031 对标 1.4nm 制程的同等晶体管密度"——这是可证伪的承诺。如果 2031 年没做到，韬定律就证伪了一次。这一点比"定律"的总体表述要科学。
  • "逻辑折叠等创新技术压缩信号传播时延"——具体到每一项工程结果是可证伪的，但作为整体框架是蕴含性陈述（无论结果如何都能解释），这是危险的。

摩尔定律之所以是"定律"，是因为它一旦被违反就被人指出来了。2016 年 ITRS 路线图正式承认摩尔定律放缓，2020 年 5nm 后单位晶体管成本不再下降，这些是摩尔定律被证伪 / 部分证伪的真实事件。摩尔定律因为被证伪而获得了科学地位。

A theory which is not refutable by any conceivable event is non-scientific. ——一个无法被任何可设想的事件反驳的理论，是非科学的。"韬定律"目前的表述，更像一个工程组织原则，而不是一个科学定律。这不贬低它的工程价值，但它不该用"定律"自居。

我的判断分两层：

  • 作为科学定律：1/5。它没有清晰的证伪条件，没有量化的衰减预测，没有跨场景的不变性陈述。
  • 作为工程范式声明：3/5。它清晰指明了优化目标（τ）、提供了实证（381 款芯片）、给出了可验证的未来承诺（2031 对标 1.4nm）。

给某科技公司的真诚建议：把"定律"改名为"τ 范式"或"何式原则"，可以保留全部叙事价值，同时不让真正的科学共同体产生反感。当外国论文写"according to Tau Scaling Law"时，他们会找不到一篇可被同行评议的、给出明确证伪条件的奠基论文。这个问题在一两年内必须解决。

波普尔的自评：我擅长"科学 vs 非科学"的划界，能让你看清"定律"这个词被滥用的危险。但商业 / 战略 / 中国语境我不在意——吴晓波会指出我的"定律"标准过严，是欧洲启蒙时代的洁癖；他可能是对的。

Michel Foucault · 福柯
话语 / 权力 · 知识考古 · 命名权 = 标准定义权

我对"韬定律是不是真定律"这个问题不感兴趣。我感兴趣的是：是谁、在什么时刻、为什么开始把它叫做"定律"——以及这个命名行为本身改变了什么。

在科技史上，命名权从来不是对真理的发现，是对话语场的占有。摩尔定律 1965 年被命名时，并不比其他数十个观察更"科学"——它甚至不是一个定理，是一篇杂志专栏文章里的趋势线。但它因为被命名为"定律"，开始组织全行业的资源分配、路线图制定、投资周期、人才教育——它以话语装置的方式重塑了它所描述的现实。

这是 performative naming——施事性命名。被叫"定律"之后，它就开始自我实现，因为整个行业按它来组织。

现在轮到"韬定律"。它是一次命名权的争夺——目标不是物理学的承认（这一点波普尔说得对，物理学家不会认），目标是组织一个新的话语场：

  • 对内：让中国半导体生态围绕"τ 优化"组织 R&D 路径、人才培养、资本流向。
  • 对外：把全球半导体行业的术语表里塞进一个中国词。当 IEEE 论文里出现"based on Tau Scaling Law"时，话语场就分叉了。
  • 对中（最关键）：在制裁压力下，用一个新的指标重新定义"领先"。如果领先 = "几纳米"，中国永远落后；如果领先 = "τ 多小"，那就是另一张比赛单子了。
权力不只是禁止，权力也生产。它生产你的衡量标准、你的"先进 / 落后"分类、你看到自己的方式。"几纳米"也是一个被生产的标准——它假装客观，其实是某些公司（拥有 EUV 的）的话语装置。"τ"是另一个标准。哪个标准胜出，取决于谁能让足够多的工程师按它来工作。

这一点我必须说清楚——这不是阴谋论。我不是说"某科技公司在搞舆论战所以这是假的"。我是说：所有定律在历史上都是这样诞生的，包括摩尔定律。把"几何缩微"称为客观、把"时间缩微"称为政治化，是双标。

真正的问题是：这个命名能不能被全球工程师社群接住。如果不能，"韬定律"就停留在中国语境内的自我命名，类似当年某些苏联式术语没能跨出冷战阵营。如果能，它就进入了人类技术词典，独立于某科技公司继续存活——那就是最高级别的成功，也是最深层意义上的"定律"。

我的判断：

  • (L3 命名层) 这是一次清醒、雄心勃勃、风险很大的命名权博弈。我不评价它对错，但我承认它的战略眼光。
  • (L5 历史层) 即便最终"韬定律"作为术语没能在国际生根，"中国公司开始尝试命名"这件事，已经是历史事件。
  • (L1 物理层) 我不在这一层评判——交给费曼。
福柯的自评：我能让你看穿命名行为背后的权力结构，看到这场博弈的真正棋盘。但具体物理 / 工程现实我不评判——而且我容易让人陷入"一切都是话语"的相对主义陷阱。马斯克和费曼会把我拽回到现实工程数据上。

① 韬定律的真实重量（5 位整合视角）

把这件事拆成 5 层独立打分，每层有不同结论，不能合并为一个简单的"是"或"否"：

层次评估结论
L1 物理层τ 不是新物理量，"以系统时延作为统一指标"是方法论组织，不是新发现部分成立
L2 工程层逻辑折叠 = 3D 堆叠 + 全栈协同；业界已有探索，某科技公司做的是系统化整合 + 量产化实在突破
L3 命名层"定律"二字过重；但命名权博弈本身是清醒的战略行为战略上有，科学上不
L4 商业层381 款芯片量产 + 麒麟 2026 实测数据是不可质疑的硬功夫；2031 承诺待验证硬
L5 历史层无论"定律"是否最终被国际接受，"中国公司首次尝试命名半导体范式"已经是历史事件分水岭

② 你应该忽视的（5 位提醒的常见误读）

  • 误读一：把"τ 替代几何"当真物理革命。这只是当一个变量被卡死时把资源转移到另一个变量的策略转移，不是范式革命。任何严肃工程师都本来就该一起优化。
  • 误读二：把"6 年 381 款芯片"等同于"摩尔定律已被替代"。替代摩尔定律的不是更小的尺寸，是不同的成功标准。这两件事不能混。
  • 误读三：把"定律"是否成立当成关键问题。真正关键的是 2031 年实测数据，以及国际工程社群是否在论文里采用 τ Scaling Law 这一术语。前者是物理验证，后者是话语扩散。
  • 误读四：因为"反对韬定律 = 不爱国"的舆论压力而拒绝独立评估。这是吴晓波点出的最危险的事——当技术成果被国家叙事绑架，技术评估的空间会被压缩。最好的爱国是严苛评估。
  • 误读五：把这件事还原为"某科技公司 PR"。反方向的过度怀疑也是错的——381 款芯片是 hardware in production，不是 PPT。需要在"全盘接受"和"全盘怀疑"之间找到分层评估的位置。

③ 决策清单（如果你是产业从业者 / 投资人 / 战略观察者）

  1. 🔴 把"是不是定律"问题搁置 24 个月 这个问题在国际工程社群独立验证之前不可能有答案。盯量产数据、盯 IEEE 论文里 τ 术语的引用频率、盯麒麟 2026 上市后的第三方拆解评测。这些是真信号，"定律"二字是噪声。
  2. 🟢 把 2031 作为锁定的判决节点 某科技公司承诺的"2031 对标 1.4nm 等效密度"是这件事少有的明确可证伪节点。建立你的跟踪表：每年问一次"距离 1.4nm 等效还有多远"。如果到 2029 年差距 < 30%，韬定律基本立住；> 50% 则承诺破产。
  3. 🟢 在你的领域里寻找 τ 视角的迁移机会 即使"韬定律"作为定律失败，"在被卡死的变量之外寻找剩余可优化变量"这个 meta 思路是真有用。SaaS 被卷入价格战时，去想响应时延 / 用户操作步数 / 集成时延等"τ 类变量"。这是马斯克的解读，可能比命名本身更有迁移价值。
  4. 🟢 关注命名权扩散的 4 个关键信号 (1) 第一篇非某科技公司作者的 IEEE 论文显式引用 τ Scaling Law；(2) 任一海外学府开设以 τ Scaling 为名的课程或 workshop；(3) 任一海外公司（哪怕一家小公司）在产品发布会上使用这个术语；(4) 任一非中文媒体把 τ 写入年度技术回顾。这 4 个信号任一出现，都是命名战的胜利里程碑。
  5. 🟡 警惕国家叙事对评估能力的侵蚀 中文舆论场里"批评韬定律 = 不爱国"的二元陷阱已经形成。主动维护你的评估独立性，把"叙事归叙事，技术归技术"作为基本纪律。这是吴晓波给的最重要提醒。
  6. 🟢 给某科技公司的真诚建议（如果你能影响） 参考波普尔的提议——把"定律"作为 PR 用语保留，把"τ 范式"或"何式原则"作为科学论文用语。这样既保留对内动员力 + 对外话语权，又让国际科学共同体有一个可严肃讨论的版本。两个版本不冲突。
  7. 🔴 不要急着站队 在前 6 步未走完之前，"韬定律是不是真的"问题没有干净答案。分层评估 + 长期观测，不站队不出口号，是技术分析者面对国家级技术叙事时唯一的尊严。

④ 一句话结论（5 位汇总，最锋利的版本）

"韬定律"作为科学定律，称谓过重；作为工程范式，言之有物；作为商业战略，是清醒的命名权博弈；作为产业史事件，无论结果如何，已经发生。真正的判决在 2031——届时如果某科技公司做出了 1.4nm 等效密度的高端芯片，并且国际工程社群开始独立采用 τ 术语，这就是 21 世纪上半叶半导体史最大的一次范式转移；如果没做到，它会被记住为"一次雄心勃勃的工程总结被命名权野心所累"。当下任何斩钉截铁的"是"或"否"，都是叙事，不是分析。

马斯克："τ 替代几何"是 PR 修辞，不是物理。但选择正确的剩余变量去发力，是优秀工程组织的标志。2031 年的 hardware 会替它说话——叙事让飞机起飞，但 hardware 决定它能不能持续飞。
吴晓波：这是中国半导体史上的分水岭事件，无论"定律"是否成立。分水岭的标志不是结果，是命名权易手——但当技术被国家叙事绑架，最大的危险是评估空间被压缩。最好的爱国是严苛评估。
波普尔：把"定律"改名为"τ 范式"，可以保留全部叙事价值，同时不让真正的科学共同体产生反感。一个不能被任何可设想的事件反驳的命题，不该用"定律"自居——但作为工程范式它站得住。
福柯：命名从来不是对真理的发现，是对话语场的占有。摩尔定律也是这样诞生的。"韬定律"是清醒、雄心勃勃、风险很大的命名权博弈——能不能进入人类技术词典，取决于全球工程师社群是否接住，那才是最深层意义上的"定律"。
