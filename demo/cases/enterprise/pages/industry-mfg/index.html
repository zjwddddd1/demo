场景 02

电路原理图 → 物料清单 BOM

从 .SchDoc Altium 原理图自动提取采购级 BOM  ·  CASE: AC-SPS 交流开关电源板

硬件工程师完成原理图设计后，采购部门需要一份物料清单用于比价下单。传统流程需人工对照图纸逐一清点元件、抄录型号、查询封装；WorkBuddy 则直接解析原理图文件，关联位号与参数，去重统计后生成标准 BOM 表。

AC-SPS.SchDoc 715 KB
OUTPUT 输出 · 采购级 BOM 表（真实成果）

WorkBuddy 实现过程
  1. 解析 OLE 文档 — 使用 olefile 解析复合文档，定位主数据流 FileHeader
  2. 切分记录 — 解码后按 |RECORD=| 切块，|KEY=VALUE| 拆字段，识别 140 个元件
  3. 父子关联 — 通过 OWNERINDEX 将位号 / 参数 / 封装关联至各自的元件本体
  4. 解码中文 — 优先取 %UTF8% 字段，普通文本按 GBK 还原，消除乱码 build_bom.py
  5. 去重统计 — 同规格元件归并，140 元件 → 64 种物料，导出 CSV + HTML
