产品概览

小白股票是一个面向「理财新手」的 A 股模拟交易系统。它不像同花顺那样堆满 K 线、指标、研报——而是把交易简化成四步引导式操作：选方向 → 填金额 → 预览 → 确认下单。持仓页配 AI 大白话解读，帮新手看懂"为什么赚 / 为什么亏"。

数据通过 腾讯财经实时行情接口 拉取真实价格，支持网页端和手机端双端浏览，通过 Firebase Firestore 实现跨设备云端数据同步。

产品定位

理财新手的第一支模拟盘

降低认知门槛：不需要懂 PE、MACD、K 线，只需要「看好 → 买入 → 持有 → 卖出」。用模拟资金（100 万虚拟币）练习交易节奏，为真实投资打基础。

设计理念

差异化

不做信息洪流，做「引导式决策」

传统炒股软件有两个痛点：(1) 信息密度太高，新手看不懂；(2) 交易流程有十几步。小白股票反其道而行——行情页只保留名称、价格、涨跌幅，交易四点即完成。

创新点

AI 持仓解读：先给结论，再给数据

持仓顶部有一段「AI 大白话」解读，分析整体盈利构成、仓位分布、风险提示。文案由规则引擎 + 自然语言模板生成，模拟 GPT 风格但无需调用 API，零延迟渲染。

双端策略

手机轻浏览 · 网页深研究

手机端去掉底栏之外的冗余 UI，一屏看完行情 + 交易；网页端保留完整表格（名称 / 现价 / 涨跌幅 / 高低 / 交易），适合深度筛选和研究场景。

云端同步机制

系统启动 → cloudPull（从 Firebase 拉取最新账户数据）→ 对比本地时间戳 → 取最新版本 → 用户操作后 cloudPush（推回云端）→ 其他设备通过 onSnapshot 实时感知变化。

防回环设计

cloudPush + onSnapshot 的竞态处理

每次 cloudPush 时记录 _lastCloudPushTs（毫秒级时间戳）。onSnapshot 收到远端更新时，先对比是否等于自己刚推送的时间戳——相等则跳过，不等才认为来自其他设备并覆盖本地。这样就避免了「本机推 → 监听到自己的更新 → 再拉回 → 再推」的死循环。

数据清洁

Firestore 不接受 undefined 值

JavaScript 对象里可能出现 undefined 值的字段（比如空的持仓记录），直接传给 Firestore 会报错 Unsupported field value: undefined。系统在每次 push 前执行 cleanUndefined()，递归剔除所有 undefined 字段。

Firebase 配置步骤

如果你要从零搭建这套系统的 Firebase 后端，需要以下步骤：

1

创建 Firebase 项目

前往 Firebase 控制台 → 新建项目（或使用已有项目）。获取 Web 应用 SDK 配置（apiKey、projectId 等五字段）。

2

开启 Firestore 数据库

左侧菜单 → Firestore Database → 创建数据库 → 选择测试模式（或生产模式后手动修改规则）。

3

配置安全规则（懒人版）

本项目 Demo 使用开放规则，允许任意读写（无 Auth 依赖）：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

⚠️ 生产环境务必改为 if request.auth != null 并接入 Firebase Auth。

4

将配置填入代码

在 index.html 中找到 firebaseConfig 对象（约第 320 行），替换为你的项目配置。重启页面即可。

为什么不用 Firebase Auth？

简化解耦，用应用层账号管理身份

起初我们接了 Firebase 匿名登录（signInAnonymously()），但遇到两个问题：(1) API Key 的 HTTP 来源限制导致 localhost 请求被拒；(2) Google Cloud Console 改白名单步骤繁琐。

最终方案：去掉 Auth，Firestore 开放读写，App 自己在应用层管理用户名密码。这样部署零摩擦，更适合 Demo 场景。真实生产环境需要换回 request.auth != null 保护。

交易流程

引导式交易

四步完成买卖

1

选择方向

买入 / 卖出，并显示当前标的名称和现价。

2

输入金额

买入输入金额（元），系统自动按现价换算可买股数（取整）；卖出输入股数，自动校验持仓。

3

预览确认

显示方向、标的、数量、本金、手续费、合计——全部明示后再点下一步。

4

下单执行

最终确认，扣除 / 增加虚拟币，更新持仓，写入交易历史，并自动同步到云端。

手续费

模拟万二点五费率

const FEE = 0.00025（即 0.025%）。买入时本金 + 手续费从虚拟币扣除，卖出时回收金额 - 手续费返还虚拟币。

为何零框架？

部署极简，无需 npm install

整个系统只有一个 index.html 文件（约 85KB），拷贝到任意 HTTP 服务器即可运行。Firebase SDK 和行情数据都通过 CDN 引入，不需要本地依赖。这对「快速丢链接给人试用」的场景非常友好。
